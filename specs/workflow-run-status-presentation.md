# 动态工作流运行状态呈现

## 产品规则

1. 动态工作流的运行状态在 UI 层使用**五态词汇**：待开始、运行中、已完成、已停止、已失败。阶段灯、子代理头像、右侧状态标记、名册计数与量条共用这一套词汇，不允许各处自行发明第六种画法。
2. 子代理头像采用用户选定的 **D2「Q 弹果冻三叶小机灵」**：软件图标的蓝、黄、绿三叶头发，圆润机身、浅色面板、深色小眼睛与暖腮红。保留样稿的大幅摇叶、果冻回弹、运行中敲键盘、完成高跳和失败小雨；替换云朵小幽灵的图形与动效。普通药丸与更多头像框仍为 32 px，侧栏为 24 px，折叠头像串保持 16 px，不撑高药丸。
3. **身体随界面主题搭配颜色，三色头发保持不变**。三叶固定使用既有蓝、黄、绿色板，叶片填色与描边均不依赖主题主色；主题切换不改变其造型或动作。机身、底部阴影、两侧耳件和敲键小手单独从 `--color-brand` 与中性色派生，不混入头发的绿色：Zai 浅色为银灰、深色为浅银灰，暖纸为暖米色，午夜蓝为柔蓝，森林为柔绿。面板保持明亮暖色，轮廓单独使用深中性色，五官保持深色；键盘、雨云和雨滴沿用冷色派生，不使用成功/失败语义色装饰角色。不新增按主题 id 分支或固定实例九色；同一主题下实例共用配色，身份只用于确定动画错相。主题切换只更新 CSS，不重挂载或重播完成动作。
4. **头像和状态标记分区**：名字右侧既有 `wf-pill-tail` 唯一绘制对勾、叉号、运行状态圈和停止符。角色内不绘制状态徽章、语义环或遮罩。用户指定的**装饰光环位于角色外侧**：圆润外圈包围角色及道具的动作范围，和角色、键盘、雨云留出可见间距；轨道与流动光带颜色加深，但不使用错误/成功色。角色、外圈和描边完整留在同一个头像框内。光带沿外圈顺时针慢流，不能穿过角色；**已停止仍显示同一光环，但角色、光带完全静止**。减少动效时所有状态保留静态光环。
5. 状态到通道的映射是唯一且固定的：

   | 状态   | D2 表情与道具           | 头像动效                         | 药丸右侧标记 | 阶段灯            |
   | ------ | ----------------------- | -------------------------------- | ------------ | ----------------- |
   | 待开始 | 圆眼微笑、三叶头发       | 叶片 ±20°、眨眼、轻呼吸与回弹     | 无           | 空心环            |
   | 运行中 | 专注小笑脸、前景小键盘   | 叶片 ±24°、交替敲键与按键高亮     | 旋转圆环     | 活动色实点 + 脉冲 |
   | 已完成 | 弯眼笑脸、同步地影       | 叶片 ±26°、16 单位高跳与回弹循环  | 对勾         | 成功色实点        |
   | 已停止 | 闭眼休息、静态三叶       | 角色和外侧装饰光环完全静止       | 中性停止符   | 中性色实点        |
   | 已失败 | 疑惑波浪嘴、雨云与小雨   | 叶片 ±16°、错相落雨与轻轻回弹     | 叉号         | 错误色实点 + 晕圈 |

   只挂载当前状态的表情和道具，不保留隐藏的键盘/小雨。缺席状态与待开始完全相同。完成持续循环高跳、蓄力压缩、落地回弹与笑脸庆祝；所有非停止状态的装饰光带持续慢流。

6. **停止不是失败**。节点结算 `outcome: "cancelled"` 显示「已停止」；run 以 `stopped` 收场时当前阶段灯显示已停止，不改写成员自身的结算事实。停止头像是静止的休息表情，不是红色叉号；只有真正的 `failed` 与 run `errored` 使用错误色状态标记。
7. 折叠规则（`aggregateRunStatuses`）：任一运行中 → 运行中；既有排队又有已结算 → 运行中；全排队 → 待开始；否则已失败优先于已停止，已停止优先于已完成。运行中刻意优先于已失败，因为读者最需要先知道「还在动吗」。
8. 编译反馈不属于 run，也不属于任何 actor：它不创建子代理头像、不给头像染色，继续使用既有的空心环画法。
9. 暂停、等待供应商等更细的活动语义不扩充五态；只有收到专用事实才作为次级活动说明。工作流节点的可选 `activity`、`wait`、`settledAt` 由引擎观察和 journal 时刻派生，时间线与侧板共用选择器。未启动不冒充等槽位；请求没有可见输出不冒充正在推理；暂停、终态、旧 attempt 与连接恢复中的历史快照不显示成实时执行。
10. 活动说明区分模型处理中、实际正文/思考输出、工具执行、同 actor 前项等待、工作流名额等待、provider 槽位等待、退避和主代理答复等待。第一次重试即可查看次数、归一化原因、等待起点/时长与下一次尝试时间；0 次数上限不显示成“最多 0 次”。详情显示已知请求/工具数、源活动时间、成功请求与已观察的最近成功交付，未知不补零；同 actor 后续 ask 不擦掉前次交付。手机点击可访问完整原因，原子会话入口保留且不增加逐 actor 的调试订阅。主会话状态面板与静态工具卡共享解释，后者年龄固定在 generatedAt；具体事件与隔离规则见 `workflow-execution-efficiency.md`。

## 状态所有者与边界

- `StepRunStatus`（`workflow-graph/types.ts`）是这套五态词汇在 UI 内的唯一类型来源；阶段灯、头像、名册、量条都从它派生。
- 引擎相位到五态的映射唯一写在 `run-status.ts`：`executing` / `repairing` / `nudged` → 运行中；`settled` 按 `outcome` 分为已完成 / 已失败 / 已停止；其余相位 → 待开始。消费者不自行判断 `outcome`。
- 阶段状态的收场只在 `timeline-model.ts` 的 `stationStatus`：成员节点先说话，之后控制流才有话说；当前阶段按 run 终态收场（已完成 / 已停止 / 已失败）。
- run 级状态（`RUN_STATUS_DOT`）与阶段/节点五态是两套词汇：run 只有 `pending / running / completed / errored / stopped`。run `errored` 不无条件把成员改写为已失败——成员有自己的结算事实。
- `packages/shared` 的会话索引 phase 摘要（`sessions-index-workflow-activity.ts`）保持既有独立四态词汇，`stopped` 当前阶段仍读作未开始；它面向侧栏概览，不与时间线五态耦合。
- 头像五官与道具由 `WorkflowAgentFace.tsx` 派生；静态 SVG 道具放在同域纯展示组件中，配色唯一由 `styles.css` 的 `.wf-agent-avatar` 局部变量和既有主题 token 派生。组件不保存主题或运行状态，不新增跨包接口。所有药丸、更多头像叠层和侧栏头像串复用同一核心；语义图标只由 `PillStatusMark` 绘制。
- 头像是无状态内联 SVG 投影，不增加依赖、计时器、观察器或媒体查询监听。CSS 只动画内部图层；所有循环使用稳定身份相位，完成角色、头发与地影共享 3.6 秒周期和相位，持续循环且同步落地。渐变 id 使用组件实例唯一 id。状态切换重新挂载角色内部层以开始新动作，主题切换不重挂载。
- 保留 D2 的 96 单位原稿坐标，统一扩展 viewBox 为 `-8 -25 112 128`，容纳 16 单位高跳、键盘、小雨及外圈间距。外圈为与角色长宽协调的圆润闭合轨道，流动由沿轨道的 dash offset 实现，避免旋转非圆形轨道时扫过角色。轨道位于 `x=-5,y=-22,width=106,height=123,rx=22`，描边不超出头像框；较平缓的圆角为键盘两端保留至少约 1 px 的 32 px 尺寸间距。停止保留光环与渐变，但没有动画；减少动效保留静态表情、道具和光环。
- 只替换头像图形、样式和相关测试/说明，不改变五态映射、节点事实、药丸高度或右侧尾槽。更多叠层的间距必须保证相邻头像五官与外圈不互相遮挡。

```text
引擎相位 / 节点 outcome → statusOfRunNode → StepRunStatus
                                          ├→ D2 表情、道具与内部 CSS 动效
                                          └→ 右侧 PillStatusMark / 阶段灯 / 名册
run.status → stationStatus（不改写节点事实）

主题 store → applyTheme → 根主题 class → 既有色板 → D2 派生配色
                                           不重挂载角色，不重播完成动作

药丸：[ 外侧光环 + D2 ] [ 名字 / 活动 ] [ 唯一状态标记 / 打开箭头 ]
停止：保留光环 → 角色与光带动画归零；状态标记仍读作已停止
```

## 验收

- 五态均使用 D2；运行中仅挂载键盘和敲键手，失败仅挂载雨云/雨滴，完成仅挂载同步地影，停止闭眼且保留光环。不存在旧小幽灵图形或 CSS。缺席状态与 pending 相同。
- 同主题、不同状态/编号的机身配色相同。切换 Zai Light、Zai Dark、Sepia Light、Midnight Blue、Forest Dark 时，身体、底部阴影、耳件与敲键手的计算色随主题更新，不残留固定绿色身体；三片叶子的填色与描边在全部主题下逐项相同。面板与五官对比度至少 4.5:1，面板与轮廓至少 3:1；亮暗界面中轮廓清晰。系统主题继续复用既有 applyTheme。
- 非停止态光带沿外侧轨道顺时针推进，颜色较旧光环加深；静态与动画极值时轨道均和角色、键盘、雨云保持可见间距。停止保留光环和渐变，所有动画立即停止，不闪红。减少动效下五态全静止，表情、道具与光环保留。
- 完成动作持续循环，包含 16 单位跳高、蓄力压缩、落地回弹和同步地影。至少观察两个周期，身体、头发和地影保持同相。主题切换不重置周期，状态切换至 done 开始循环庆祝。
- 所有角色、道具、外圈、描边和动作极值留在 viewBox 内。普通/侧栏药丸和头像框维持 32/24 px，折叠串 16 px，workspace/unresolved 图标维持既有尺寸。更多头像相邻五官和外圈不互相遮挡。
- 所有语义状态标记只有一枚，位于名字右侧尾槽，和头像无边界重叠；头像内部不存在对勾、叉号、停止符或语义环。光环是无障碍隐藏的纯装饰层。
- 浏览器 E2E 场景：五态并排 → 核对键盘、小雨、持续高跳和静止光环 → 点击状态切换和药丸打开 → 切换全部主题并测量色值与对比度 → 检查 32/24/16 px、窄药丸、390 px 手机视口、更多叠层和长名字 → 抽样完整动效周期核对边界与外圈间距 → 减少动效保持所有静态图形。
- run errored 不改写取消节点；名册和量条保留已停止档，编译失败仍不创建头像。
