# 动态工作流运行状态呈现

## 产品规则

1. 动态工作流的运行状态在 UI 层使用**五态词汇**：待开始、运行中、已完成、已停止、已失败。阶段灯、子代理头像、右侧状态标记、名册计数与量条共用这一套词汇，不允许各处自行发明第六种画法。
2. 子代理头像采用用户选定的 **B「云朵小幽灵」**：圆润云朵身体、波浪下摆、深色眼睛、腮红和拟人嘴型。用眼神、眉毛、嘴型及轻量动作表达情绪，不再使用轨道晶核、圆角方块机身或抽象状态刻印。14–16 px 下优先保证完整脸部与五官可读。
3. 小幽灵配色**跟随当前界面主题**，不再固定紫色，也不按实例编号将身体染成独立九色。身体、轮廓、腮红和泪滴从既有 `--color-brand`、`--color-background` 与中性色 token 派生：Zai 亮暗使用银灰，暖纸使用米色，午夜蓝使用柔蓝，森林使用柔绿；`system` 随既有主题链路落到 Zai 亮暗。同一主题下各实例共用协调的配色，身份仍由名字区分，编号或名字散列只为动画错相提供稳定输入。状态变化不改变配色；亮色身体配中性深色五官，避免暗色主题下五官反白而失去对比。
4. **头像和状态标记分区**：左侧小幽灵只负责表情，名字居中，对勾、叉号、运行状态圈、停止符统一位于药丸右侧的既有 `wf-pill-tail` 槽。禁止把这些符号、状态圈、徽章或遮罩画在头像内，也不围住头像。一个药丸至多一个状态标记；原有右侧悬停打开箭头继续复用同一个尾槽。
5. 状态到通道的映射是唯一且固定的：

   | 状态   | 小幽灵表情                   | 头像动效                     | 药丸右侧标记 | 阶段灯            |
   | ------ | ---------------------------- | ---------------------------- | ------------ | ----------------- |
   | 待开始 | 睁圆眼、微抬眉、小圆嘴       | 偶尔眨眼与好奇张望           | 无           | 空心环            |
   | 运行中 | 专注眼神、内收眉、抿嘴       | 持续轻浮动、眼神移动与眨眼   | 旋转圆环     | 活动色实点 + 脉冲 |
   | 已完成 | 眯眼微笑、张嘴开心           | 轻轻点头一次，然后保持笑脸   | 对勾         | 成功色实点        |
   | 已停止 | 闭眼、放松嘴型、轻歪头休息   | 完全静止                     | 中性停止符   | 中性色实点        |
   | 已失败 | 委屈眉、下弯嘴、脸侧小泪滴   | 克制的小泪滴与低频轻叹动作   | 叉号         | 错误色实点 + 晕圈 |

   五态只挂载当前所需的五官，不保留隐藏的表情组。缺席状态与待开始使用完全相同的外观。眼神动作不能移动布局盒、挤占名字或遮住五官。

6. **停止不是失败**。节点结算 `outcome: "cancelled"` 显示「已停止」；run 以 `stopped` 收场时当前阶段灯显示已停止，不改写成员自身的结算事实。停止头像是静止的休息表情，不是红色叉号；只有真正的 `failed` 与 run `errored` 使用错误色状态标记。
7. 折叠规则（`aggregateRunStatuses`）：任一运行中 → 运行中；既有排队又有已结算 → 运行中；全排队 → 待开始；否则已失败优先于已停止，已停止优先于已完成。运行中刻意优先于已失败，因为读者最需要先知道「还在动吗」。
8. 编译反馈不属于 run，也不属于任何 actor：它不创建子代理头像、不给头像染色，继续使用既有的空心环画法。
9. 暂停、等待供应商等更细的活动语义（`parked` / `unfinished`）当前时间线快照无法可靠表达，不从此处推断，也不新增第六态。需要时应显式接入专用 roster 状态模型。

## 状态所有者与边界

- `StepRunStatus`（`workflow-graph/types.ts`）是这套五态词汇在 UI 内的唯一类型来源；阶段灯、头像、名册、量条都从它派生。
- 引擎相位到五态的映射唯一写在 `run-status.ts`：`executing` / `repairing` / `nudged` → 运行中；`settled` 按 `outcome` 分为已完成 / 已失败 / 已停止；其余相位 → 待开始。消费者不自行判断 `outcome`。
- 阶段状态的收场只在 `timeline-model.ts` 的 `stationStatus`：成员节点先说话，之后控制流才有话说；当前阶段按 run 终态收场（已完成 / 已停止 / 已失败）。
- run 级状态（`RUN_STATUS_DOT`）与阶段/节点五态是两套词汇：run 只有 `pending / running / completed / errored / stopped`。run `errored` 不无条件把成员改写为已失败——成员有自己的结算事实。
- `packages/shared` 的会话索引 phase 摘要（`sessions-index-workflow-activity.ts`）保持既有独立四态词汇，`stopped` 当前阶段仍读作未开始；它面向侧栏概览，不与时间线五态耦合。
- 头像五官由 `WorkflowAgentFace.tsx` 派生，配色唯一由 `styles.css` 的 `.wf-agent-avatar` 局部变量和既有主题 token 派生；组件不传内联身份色、不读取或保存另一份主题状态，不增加按主题 id 分支。`WorkflowAgentPill`、更多头像叠层与侧栏头像串均复用它。状态图标只由 `WorkflowAgentPill.tsx` 的 `PillStatusMark` 绘制并放入右侧尾槽，不在头像内复制。
- 头像是无状态的内联 SVG 投影，不使用 GIF/APNG 运行时资源，也不创建定时器、观察器、媒体查询监听或第二套运行状态。CSS 根据五态执行内部图层动画，循环相位按实例编号（缺席时按名字散列）确定，不使用随机数。渐变 id 对每个组件实例唯一，避免多头像串色。
- 图形使用 20×20 viewBox，实际布局盒由调用方 14/16 px 尺寸控制；不设置 20 px 最小尺寸。身体、五官、泪滴与动画范围都留在 viewBox 内；不用 filter、mask 或外侧状态环。小幽灵浅色身体配深色五官，不因暗色主题反转成浅色眼睛。
- 本次只替换共享头像核心与相关样式，不修改节点状态映射、协议、持久化、事件顺序、右侧状态图标规则及消费面入口。旧晶核图形与 CSS 完整移除，不新增依赖。

```text
引擎相位 ──statusOfRunNode──┐
                            ├─→ StepRunStatus(五态) ─┬─→ 左侧：小幽灵五官 + CSS 动效
节点 outcome ───────────────┘                        ├─→ 右侧尾槽：PillStatusMark
                            ┌───────────────────────┴─→ 阶段灯 / 名册 / 量条
run.status ──stationStatus──┘

主题 store → applyTheme → 根主题 class → 既有颜色 token → CSS 派生小幽灵配色
                                              不增主题状态，不重挂载头像

药丸布局： [ 小幽灵头像 ]  [ 名字 / 活动 ]  [ 对勾 / 叉号 / 状态圈 / 停止符 ]
                不覆盖                       复用既有尾槽与打开箭头
```

## 验收

- 同一次运行并列展示五态时，小幽灵身体一致，五种表情可以区分；已完成是笑脸，已停止是闭眼休息，已失败是委屈与泪滴。
- 同一主题下切换五态时配色始终不变，只改变表情与动作。切换界面主题后，现有头像立即通过 CSS 换色，不重挂载、不重播一次性动作。不同编号不再残留固定紫色或九色身体。缺席状态与待开始相同；多实例的渐变 id 不冲突，动画错相确定且可复现。
- 浏览器依次检查 Zai Light、Zai Dark、Sepia Light、Midnight Blue、Forest Dark，核对身体渐变、轮廓与装饰实际计算色随主题变化，五官对身体渐变最深色端的对比度至少 4.5:1。跟随系统仍由既有 `applyTheme` 链路选择 Zai 配色，不新增监听器。
- 头像内不存在对勾、叉号、状态圈、停止符、遮罩或覆盖徽章。非待开始药丸的状态标记只有一枚，位于名字右侧的尾槽内，与头像边界完全不重叠。
- 待开始偶尔眨眼张望，运行中的轻浮动与眼神动作持续可见；完成只执行一次入场动作，之后静止；停止全程无动画；失败只出现克制的泪滴与轻叹。
- 系统开启 `prefers-reduced-motion: reduce` 时，所有头像动作停止，五种表情落在清晰静态帧；右侧语义标记仍保留。灰阶下也不靠身体色判断状态。
- 一个 run `errored`、同时已有取消节点的运行，取消节点保持「已停止」，不会被 run 的终态改写成已失败。
- 名册计数行与量条包含「已停止」一档，为零时不显示；名册分组标题与计数行的顺序在所有面板一致。
- 普通药丸、侧栏行、更多头像叠层、折叠头像串均使用小幽灵；workspace / unresolved 车道仍使用既有图标。桌面和手机 Web 语义一致，不引入额外布局宽度。
- 浏览器场景：五态并排 → 检查实际 14/16 px 头像与右侧尾槽边界 → 点击状态切换，核对表情与右侧图标同步 → 检查打开药丸回调 → 切换亮暗背景和减少动效 → 验证 390 px 手机宽度无横向溢出。
- 编译失败的草稿不出现任何头像或错误色，仍是空心环。
