# 无可用模型横幅

## 产品规则

1. 发送消息时模型注册表为空（`model_config_missing`）触发聊天横幅「当前没有可用模型」。
2. 文案只引导配置自定义模型；不出现「开通编程套餐 / Upgrade」话术——OAuth 授权登录已移除，
   编程套餐开通入口随登录一并下线（2026-09-29）。
3. 横幅操作按钮保留：**配置模型**（打开模型设置）与**关闭**；「升级」按钮及其背后的
   套餐升级弹窗入口从横幅移除（2026-09-29 二次清理：页脚用量升级、闲时任务升级引导、
   模型设置套餐卡的升级/订阅按钮、Start Plan 余额 CTA、会话额度横幅升级按钮等**全部
   升级入口一并下线**，CodingPlanUpgradeDialog/EmbeddedWebview 购买弹窗组件整体删除；
   套餐额度/状态展示保留，Linux arm64 等无清单平台走手动更新）。

## 验收

- 无可用模型时横幅文案为「当前没有可用模型。请配置自定义模型。」（英文
  "No model available. Set a custom model."）。
- 横幅不再显示「升级」按钮；「配置模型」按钮仍可打开模型设置。
