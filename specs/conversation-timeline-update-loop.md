# 会话时间线更新循环回归

## 产品规则

桌面和 Web 的会话时间线显示较长历史、工具与推理内容时，挂载、会话切换、局部错误边界重试及异步快照落地都必须收敛，不能触发 React 更新深度超限。滚动位置与测高属于时间线实例，本地状态不能回写会话事实；查找匹配数属于父级查找视图，只有实际变化才需要通知。

远端 replayable 与桌面 continuous 都消费同一投影行，时间线不得为了诊断或重试重新发起命令。局部错误边界保留重试能力，不刷新整个应用或清除会话内容。

## 所有者与顺序

```text
CLI/Host 会话投影 -> SessionPane 订阅快照 -> ConversationTimeline 虚拟列表
                                                -> 本地测高/滚动/导航状态
                                                -> (匹配事实变化时) 查找视图状态
错误边界重试 -> 重挂当前会话的时间线 -> 读取现有投影 -> 收敛
```

时间线测量只响应 DOM 实际尺寸变化；滚动补发只同步当前元素的观察者。重复同值的快照、查找结果或滚动状态不得形成新的同步提交链。切换会话时旧订阅或延迟测量不能写入新时间线。

生产错误边界捕获到 React 异常时，必须将 scope、错误消息及组件堆栈写入本地桌面诊断日志，不能在生产版使用被禁用的普通 UI 日志方法；本地日志是诊断通道，不替代错误边界本身的恢复或 ARMS 上报。Web 没有桌面日志桥时保持界面降级与既有上报。

## 验收

- 使用合成的多轮长历史（包括工具/推理行）覆盖首次挂载、空窗到快照、会话切换和局部重挂；在桌面宽度和手机 Web 宽度均无 `pageerror`、React 更新深度警告或局部错误回退。
- 测试区分稳定行引用与内容相同的新行引用、显示/隐藏两轮以上的导航 rail、重复滚动及动态测高；以可见行数、滚动位置与渲染提交是否收敛作为观测，不仅断言静态 HTML。
- 验证原有查找、历史分页、底部锚定和跨会话滚动记忆未回归。未能复现原错误时不得将测试通过误称为根因修复。
