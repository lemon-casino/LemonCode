# 欢迎页登录入口

## 产品规则

0. 桌面冷启动使用白璃、爱弥斯或自定义动画时，首次欢迎页在动画完整背景上渐显原有卡片，背景视频/声音或 Canvas 眨眼继续播放；无边框窗口中卡片与底层全屏动画明确 no-drag，鼠标进入和回车复用同一路径。Root 只把 `startup-provider-required` 投影为 `welcome`，其它登录来源仍为 `attention`。进入/取消仍使用下述原完成语义，异步完成中防止重复操作；只有真实 Root ready 才允许动画交接。原始/关闭/跳过/错误/减少动态效果仍显示普通欢迎页；手机与远控恢复不增加动画或欢迎门禁。详见 desktop-startup-animation.md。

1. 欢迎来到 LCode 首屏不展示“连接 Z.ai 继续使用”和“连接 BigModel 继续使用”。
2. 首屏只提供“进入”和“取消”。“进入”使用现有暂时跳过的完成原因 `skip`，不创建账号连接，不要求选择供应商或填写 API Key。
3. “取消”关闭本次欢迎入口，不写入 API Key，不触发 OAuth。
4. API Key 表单仍保留继续、取消、暂时跳过，供从其他入口打开时使用。欢迎首屏不再把“使用 API key”作为进入应用的必经步骤。
5. OAuth 授权登录已移除（2026-09-29）：欢迎首屏不再展示“连接账号，开始使用 LCode”副标题，仅保留标题“欢迎来到 LCode”与“进入/取消”。
6. 进入工作区后，侧栏 footer 身份区显示当前系统用户名（`IPlatformService.getSystemUsername`，仅 Desktop 实现；Web/手机视图回退显示“LCode”）；无账号时头像写死为品牌 L 徽标（`app-logo.svg`，与左上角品牌一致）。
7. 品牌徽标不再兼任侧边栏折叠按钮（2026-09-29）：顶部浮层（Windows/Linux 自绘标题栏）与侧栏收起栏的左上角直接显示侧边栏折叠/展开图标，悬停切换品牌徽标的旧形态移除；设置页左上角的品牌标（非按钮）保留。
8. 品牌徽标头像外圈有一圈常驻光环（2026-09-30）：颜色只取 `--color-brand`，光带沿圆周顺时针流动。光环是纯装饰（`aria-hidden`），只跟随主题主色，不引入新主题变量，也不表示登录、连接或任务状态。只有无账号的品牌徽标态渲染光环；真实用户头像与 OAuth 恢复态不叠加。`prefers-reduced-motion: reduce` 时停止流动、保留静态光环。光环绘制在头像 32px 盒内（footer 触发按钮 `overflow-hidden` 且 `pl-0`，向外发光会被左侧裁切）。

## 验收

- 首屏看不到两个账号连接按钮。
- 首屏看不到“连接账号，开始使用 LCode”副标题。
- 点击进入后，完成原因是 `skip`。
- 点击取消不调用跳过保存，也不启动 OAuth。
- 进入工作区后 footer 身份区显示系统用户名（Desktop）；头像为品牌 L 徽标。
- 无账号时品牌徽标头像外圈可见主题色流动光环；切换 6 套主题时光环颜色跟随该主题 `--color-brand`；已登录用户头像不显示光环；系统开启「减少动态效果」时光环静止。
- 工作区顶部浮层与侧栏收起栏的左上角直接显示侧边栏折叠/展开图标（无品牌徽标悬停切换）；点击折叠/展开行为不变。
