# 设置侧栏顺序和尺寸

## 产品规则

- 保留基础设置、Agent 能力、编码、数据与统计的分组顺序；每组菜单按当前语言名称的字数从短到长排列，不计空白字符，按 Unicode 字符计数，同长度保留注册顺序。只计算菜单标题，不包含 Beta 等附加徽标。
- 切换语言时重算显示顺序；平台及功能开关过滤仍由现有设置配置入口处理，隐藏项不参与排列。分区 id、上次访问记录、深链接与当前选中项不因重排而改变。
- 菜单项统一使用 `text-ui-base`、`font-medium`、相同的行高与高度；选中态只改变主题背景和文字颜色，不改变字号或字重。所有图标使用同一 `size-4` 图标框，文字与图标间距一致。分组标题保持独立的 `text-ui-sm` 层级。
- 桌面显示文字与图标，手机沿用现有图标导航与辅助名称；支持中英文、七主题与界面字号设置，不横向溢出。

## 所有者与接口

`SettingsPage` 传入当前 intl 标题解析器，`createSettingsPageConfig` 仅从现有平台可见注册项派生分组内顺序，不创建状态、持久化或新的导航写入路径。未传标题解析器的非呈现消费者保留注册顺序。

```text
现有平台/功能过滤 + IntlProvider 当前语言
    -> createSettingsPageConfig（只读派生短到长分组）
    -> SettingsPage 原有侧栏与 activeSection(id)
点击 -> 原有 setActiveSettingsSection -> 原有访问偏好
```

## 验收

- 单测覆盖中英文各组长度单调、同长度稳定、平台过滤、未传解析器保留原顺序与注册配置不被修改。
- 浏览器挂载真实 SettingsPage，验证分组内名称顺序、所有项的文字字号/字重和图标框一致、选中前后尺寸一致、导航仍到达同一分区。
- 覆盖中英文、七主题、桌面与 390px 图标导航，执行 typecheck、lint 和 changed 架构检查。
