# Native provider adapters: source and license

These Node/TypeScript adapters were written for LCode after consulting and adapting the provider protocols and behavior in [yetone/magpie](https://github.com/yetone/magpie/tree/93c5d846ca2b05ac8ca961956304104e5d112845), revision `93c5d846ca2b05ac8ca961956304104e5d112845`. The inspected upstream checkout was clean. They are a TypeScript adaptation, not an unmodified copy of the Go implementation and not a clean-room implementation.

The upstream root [LICENSE](https://github.com/yetone/magpie/blob/93c5d846ca2b05ac8ca961956304104e5d112845/LICENSE) is MIT and identifies `Copyright (c) 2026 yetone`. Its complete original text is retained in [LICENSE.magpie](./LICENSE.magpie). This attribution covers upstream-derived protocol and behavioral portions. LCode-specific account context integration, Windows command resolution, process/stream ownership, tool ID isolation, and new fixtures are local work; their presence here does not attribute all local code to upstream.

Additional detail adaptations in this revision:

The subsequent 2026-10-11 audit also aligns Copilot editor model API headers with `internal/provider/account.go:copilotAPIHeaders` while keeping GitHub quota headers separate, and Claude file-import string/array scopes with `internal/provider/login_import.go:loginEntry`. These changes do not alter pinned plugin files or generated worker source.

Tool schema compatibility added on 2026-10-11: `google-schema.ts` follows the bounded Code Assist `plainSchema` conversion in `internal/gateway/codeassist.go`; `tool-schema.ts` follows object-root folding in `internal/provider/grok.go`, `internal/gateway/object_root.go` and Cline's schema-only oneOf lowering in `internal/gateway/oneof_schema.go`. The original tool schema remains the execution validator; these adapters project the schema offered to the model and do not rename tools or wrap their call arguments. Both native adapters and the generated plugin worker consume these helpers. Factory retains its pinned wrapping/unwrapping implementation.

The JSONC parser, injectable local IO, bounded import runner, stable Host identity injection, SDK option projection, and Copilot Auto stream protocol adapters are local implementations of the integration contract. Upstream protocol/behavior adaptations remain covered by the retained MIT attribution above. Public model metadata is fetched at runtime without account credentials; it is not a bundled copy of a third-party catalog.

The native adapters do not bundle the magpie Go application, its dependencies, or the Claude Code executable. Claude Code remains an external user-installed dependency. Vendor service names and public installed-app OAuth identifiers describe interoperability; they do not imply endorsement or transfer vendor service rights.

## Distribution notices

The adaptation is registered in `third-party/copied-components.json`. `node scripts/licenses.mjs notices` includes the retained license text and source metadata in the repository's generated `THIRD-PARTY-NOTICES.md` and `third-party/inventory.json`. Existing Desktop/CLI notice staging consumes those generated documents. Run `node scripts/licenses.mjs check` after regeneration. Regenerate notices after changes to any registered source root; do not hand-edit the generated notice or inventory.

The license file is kept byte-for-byte under `.gitattributes`. Tests and runtime code do not read a sibling magpie checkout, fetch source dynamically, or depend on this documentation being present at runtime. The shared Google wire helper is also embedded in the plugin worker; its upstream license remains part of the same distribution notices.
