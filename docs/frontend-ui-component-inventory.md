# 前端控件盘点清单

2026-10-12 源码位置清单，配套 [前端控件组件化改造方案](../specs/frontend-ui-component-migration.md)。用于定位需要组件收敛的文件，不表示所有位置都有视觉缺陷，也不代表已经实施替换。

## 口径

- 扫描 packages/ui/src、packages/web/src、packages/desktop/src/renderer、apps/lcode-cli/packages/debug/src 中的非测试 .tsx/.jsx/.html。
- JSX 使用 TypeScript AST；HTML 使用标签扫描并排除注释和脚本。排除 packages/ui/src/components/ui/，该目录为已有基础组件，其 README 要求不修改。
- 另检查 renderer、Web 和 debug 的动态 DOM 创建；debug/src/network-model.ts:18 的屏幕外复制 textarea 与 Web 临时下载 anchor 不计入可见控件候选，保留其原有桥接功能。
- 计数单位为源码起始标签位置；map 循环只计一次。button、label、details、summary、可见输入与隐藏文件输入分开记录。
- 组件中的必要 HTML 不等于系统控件外观。具有 option/radio/tab/checkbox/switch 等角色的按钮需要语义适配；普通可见控件应组件化。
- 行号会随实施变化。优先替换表中的 select、checkbox、range；隐藏文件输入保留。运行时外观与可达性仍需前后截图和交互验证。
